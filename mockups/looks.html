Scuffed Hunter · Look-Auswahl

Drei Looks, ein Jäger. Welcher wird gebaut?

Jeder Screen ist eine live gerenderte 3D-Szene mit dem echten HUD-Layout in Handy-Querformat (19.5:9, iPhone-Proportionen). Gleiche Steuerung, gleiche Infos, nur der Look ändert sich. Der Spielinhalt bleibt bei allen drei gleich.

  • 3D Third-Person
  • P2P WebRTC, 1–4 Spieler
  • Waffen Großschwert · Bogen · Doppelschwerter
  • Touch Stick + Buttons + Lock-On
  • Save lokal
  • Jagd 5–10 min
  • Monster MH-Parodien
  • Host GitHub Pages

Tipp: Handy quer halten, dann sind die Screens fast in Originalgröße.
